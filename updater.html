Обновление Telegram-постов

Собирает посты из канала в файл tg-posts.js. Новые добавляются к уже сохранённым — ничего не теряется.

⚠️ Не выкладывайте эту страницу в интернет.

1. Данные бота

@BotFather → /mybots → ваш бот → API Token
Ваш ID уже подставлен

2. Накопление — что уже есть в файле

Выберите ваш текущий tg-posts.js, чтобы updater добавил новые посты к существующим. Если не выберете — он возьмёт предыдущий результат из памяти браузера.

3. Способ загрузки

  1. Нажмите кнопку ниже — откроется ссылка
  2. Скопируйте весь текст из новой вкладки (Ctrl+A → Ctrl+C)
  3. Вставьте в поле ниже и нажмите «Обработать»
https://api.telegram.org/bot.../getUpdates

4. Превью постов

Нажмите одну из кнопок:

Скопировали? Откройте tg-posts.js в Блокноте (правый клик → Открыть с помощью → Блокнот), удалите всё старое (Ctrl+A → Delete), вставьте новое (Ctrl+V) и сохраните (Ctrl+S).

5. Что делать после

  1. Сохранить tg-posts.js в папку ea-life-site
  2. Открыть index.html в браузере
  3. Нажать Ctrl+Shift+R
